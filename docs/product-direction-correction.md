# SleepFlow Studio 产品方向纠正

日期：2026-07-18
本轮范围：产品方向审计与主导航纠正。不会删除现有代码、Figma 设计、SQLite 结构或匿名演示数据。

## 修正后的定位

SleepFlow Studio
渠道素材数据分析与复盘工作台

面向的首要工作流是：用户导入表格或截图数据，确认字段与口径，再分析单条素材、进行素材比较、生成周度复盘与竞品对标。它不是要求用户每天手工创建产品档案、素材档案或复杂经营对象的管理后台。

## 页面审计

| 现有页面 | 新方向处理 | 可复用内容 |
| --- | --- | --- |
| 工作驾驶舱 | 改为数据总览 | 数据周期、筛选、匿名来源标识、素材快照、状态提示 |
| 数据导入中心 | 保留并改为数据导入 | CSV/XLSX 本机解析、字段映射、校验、人工确认、撤销 |
| 单条素材详情 | 改为单条素材分析入口 | 快照指标、逐秒时间线、内容段、证据与数据限制 |
| 表现分析中心 | 改为素材对比 | 渠道筛选、快照比较、素材表格 |
| 素材复盘 | 暂从主导航隐藏 | 事实/观察/假设/动作结构，后续并入周度复盘 |
| 周会报告 | 改为周度复盘 | 报告章节与会话草稿结构 |
| 指标口径 | 改为指标词典 | 指标字段、来源、口径状态提示 |
| 产品知识、素材资产、经营目标 | 从主导航隐藏，保留内部支持路径 | 现有 CRUD、关系、版本、目标、数据库结构 |
| 竞品对标、历史报告 | 新建为诚实的导航入口 | 不预设竞品品牌，不伪造历史报告 |

## 主导航

1. 数据总览
2. 数据导入
3. 单条素材分析
4. 素材对比
5. 周度复盘
6. 竞品对标
7. 指标词典
8. 历史报告

设置区后续保留：数据口径、导入模板、匹配规则、AI 分析设置、隐私设置。

## 本轮隐藏与保留

- 隐藏：新增产品、新增素材、产品档案、素材资产、经营目标等管理型首页入口。
- 保留：相关页面、API、Prisma 模型、迁移、种子和数据库数据，供导入匹配及后续功能复用。
- 不在本轮实现：截图 OCR、视频智能理解、自动渠道抓取、自动投流、自动暂停或追投、公开部署。

## 下一阶段的页面重构顺序

1. 指标词典与数据口径模型。
2. CSV/XLSX/截图导入及截图结果人工校对。
3. 单条素材分析、逐秒曲线和人工时间线标记。
4. 安全公式演示、内部目标和历史基准。
5. 周度复盘和竞品对标。

## 判断与表达约束

- 不使用固定行业“好/坏”阈值。
- 结论必须说明数据来源、周期、口径、样本与基准。
- 将数据事实、内容观察、可能原因、待验证假设和下一步建议分开。
- 不把 OCR、截图识别或视频智能理解结果直接当作真实数据；必须由用户确认。
- 不将支付 ROI、净成交 ROI 与其他 ROI 默认视为同一指标。
