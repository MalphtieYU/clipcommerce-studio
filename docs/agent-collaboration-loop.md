# Workspace-agent collaboration loop

ClipCommerce Studio does not require teams to adopt a new workflow. It can remain a local base for a department's existing data and review records; the `adaptive-work-improvement` skill helps an agent understand, organize, and return useful feedback from that already-authorized information.

```text
Existing imported/recorded data → user generates a collaboration packet → authorized agent organizes and analyzes
→ facts, gaps, and suggestions → human confirmation → feedback saved to the workspace → next review
```

## What a collaboration packet contains

In **Team Work Context**, choose a team record and select **Generate collaboration packet**. The local workspace prepares:

- current objective, tasks, success signals, constraints, and agent boundary;
- imported non-demo assets, strategy labels, and performance snapshots;
- channel-native summaries, available fields, and known data gaps;
- that team's previous advisory feedback.

It excludes environment variables, local file paths, advertising-account identifiers, customer-level data, and demo snapshots. Generation and sharing are user-initiated; the current user and organization decide which agent and destination are authorized.

## Ask an agent to be useful

Give the packet with the current task and ask the agent to:

1. state the data scope, definitions, and gaps first;
2. separate facts, interpretations, and testable hypotheses;
3. compare numbers only when channel, period, attribution, and delivery scope are compatible;
4. use real asset labels, performance, and team goals for no more than three suggestions;
5. distinguish what can be discussed now, what needs data, and what needs human approval;
6. return structured feedback to Team Work Context for the next review.

The skill does not automatically read the database or write conclusions back. Generating the packet and saving feedback are separate, explicit user-authorized actions.

## Impact on existing teams

There is no default impact. A department can keep using its current agent, documents, spreadsheets, and projects. Generate a packet only when the team wants the agent to reference workspace data; no repeat upload or project migration is required.

If feedback shows that a field, metric, or workflow does not fit a team, propose the smallest optional adjustment and trial. Do not automatically transfer one team's lesson to another.
