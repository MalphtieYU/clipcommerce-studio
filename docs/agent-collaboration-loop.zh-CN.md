# 工作台与智能体协作闭环

ClipCommerce Studio 继续作为部门已有数据、素材和复盘记录的本地底座；`adaptive-work-improvement` Skill 则帮助智能体更好地理解、整理和反馈这些真实信息。生成数据包和保存反馈都必须由用户主动触发，不会自动影响其他项目或 agent。

## 使用步骤

1. 正常按原有方式导入或记录数据；不需要为了 Skill 重新上传。
2. 在“团队工作上下文”中建立/选择部门目标和边界。
3. 主动点击“生成协作数据包”。其中只包含精简的非演示数据、策略标签、数据缺口和已确认可分享的上下文；不会包含密钥、环境变量、本地路径、账户标识或客户级数据。
4. 将数据包与当前任务交给已授权的 agent。
5. 要求 agent 区分事实、推断、假设和待确认事项；让它针对已有数据给出最多三条建议。
6. 人工判断后，将有价值的反馈保存回工作台，用于下次复盘。

默认不影响任何既有流程。一个部门的数据和经验也不会自动推广给其他部门。
