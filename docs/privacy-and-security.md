# 隐私与安全

- 真实数据、素材、截图、水印、密钥与内部报告禁止进入 Git。
- 上传限制允许的文件类型、大小和解析行数；CSV/XLSX 文本需中和公式前缀。
- 当前 MVP 的 XLSX 解析仅在绑定至 `127.0.0.1` 的本机服务中执行；文件内容不会发送给第三方服务。
- 导入先预览再确认，批次可撤销；删除需要二次确认。
- 导出前检查敏感字段；AI 日志默认仅保留结构化摘要与审计元数据。
- 所有数据分析与变更记录审计日志。

## 依赖审查状态（2026-07-17）

- 已移除 `xlsx` 依赖：其公开已知的原型污染与 ReDoS 高危问题不再进入本地依赖树。
- 当前 `npm audit` 仍报告 Prisma 工具链间接依赖的 3 项高危问题；升级需要同时验证 Prisma 的 Windows Schema Engine 兼容性，未执行强制升级。
- CSV/XLSX 解析、预览校验、导入批次撤销均仅在本机服务中执行；文件本体不持久化。登录、远程访问、对象存储和多用户权限控制尚未接入，因此不得暴露为公共业务入口。

## XLSX 导入页选择规则（2026-07-18）

- 仅将选中的无公式数据页用于导入；同一工作簿中其他页的公式不会被计算、读取或写入数据库。
- 如果不存在无公式的数据页，则拒绝导入并提示用户复制需要的数据到无公式页签。
- 隐藏工作表、隐藏行列、当前导入页公式和公式注入前缀仍一律拒绝；这避免工作簿结构绕过与后续导出时的公式注入风险。
