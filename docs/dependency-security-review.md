# 依赖与运行时安全复核

复核日期：2026-07-18。

## 结果

npm audit --omit=dev --json：0 high、0 critical、2 moderate。

唯一依赖链为 exceljs → uuid。uuid 的受影响范围低于 11.1.1，公告为缓冲区边界检查问题；当前 ExcelJS 4.x 将它作为传递依赖。自动修复会将 ExcelJS 降级到 3.4.0，属于不合理的重大回退，因此没有执行 npm audit fix --force。

## 当前缓解

- XLSX 仅在本机 API 中解析，服务绑定 127.0.0.1。
- 请求体、文件大小、工作簿条目数、工作表文本大小、行列数均有限制。
- 拒绝隐藏工作表/行/列、公式单元格及公式注入前缀。
- CSV 在浏览器本地解析；XLSX 不发送到第三方。
- 数据库、导入文件、导出文件、环境文件与真实素材均被 .gitignore 排除。
- 日志仅记录方法、路径、状态和耗时，不记录请求正文、文件内容或密钥。
- 删除产品和素材采用归档；导入批次可撤销并写入审计日志。

## 跟进

在 ExcelJS 发布兼容修复并移除受影响 uuid 版本后升级；在引入远程访问、登录、对象存储或真实业务数据前，必须增加认证、授权、CSRF 防护、速率限制、恶意文件扫描和独立的安全复审。
