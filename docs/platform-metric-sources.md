# 抖音与天猫指标口径依据

本工作台优先接收抖音/巨量与天猫生意参谋导出的原始字段。平台原生字段不在前端重算；工作台计算字段会明确列出分子、分母和适用平台。

## 抖音 / 巨量

- 指标范围：展示数、点击数、点击率、转化率、消耗、点击成本、千次展示成本、播放数与完播率。
- 官方将点击率用于观察视频的点击吸引力，转化率用于观察点击后的进一步转化能力；素材开头、定向、转化号召和落地页均可能影响结果。
- 商品经营分析采用“商品点击—下单—支付”的漏斗。工作台仅在同一日期、流量来源、位置来源与投放目标下计算相邻层转化率。
- 官方资料：
  - [巨量纵横用户手册](https://school.oceanengine.com/product_help/content/668400000010/105352)
  - [巨量引擎广告创建与投放说明](https://support.oceanengine.com/support/content/130495)
  - [巨量纵横企业号/商品经营分析说明](https://school.oceanengine.com/product_detail?id=214&type=course)

## 天猫 / 生意参谋

- 访客数（UV）是去重人数；浏览量（PV）是访问次数，二者不能混为同一单位。
- 商品加购人数是统计日期内新增点击加购的去重人数；支付买家数是完成支付的去重买家人数。
- 支付金额为买家支付给商家的金额，官方定义未剔除事后退款；工作台不会把它称为净成交金额。
- 支付转化率仅使用同一层级（店铺或商品）、同一周期的支付买家数与访客数计算；客单价使用同一维度的支付金额与支付买家数计算。
- 官方资料：
  - [生意参谋数据字典](https://developer.alibaba.com/docs/doc.htm?articleId=120314&docType=1&treeId=336)
  - [生意参谋产品说明](https://developer.alibaba.com/docs/doc.htm?articleId=103513&docType=1&treeId=47)

## 导入与趋势分析规则

- `素材表现` 导入支持：数据周期开始/结束、消耗、展示、播放、点击、商品点击、加购、支付、成交/支付金额、CTR、CVR 与支付 ROI。
- 每一行是一条素材在一个渠道、一个统计周期内的快照；同一素材至少有两个日期/周期的相同指标，工作台才绘制趋势曲线。
- 曲线和自动复盘只描述真实导入数据的变化；不会补模拟点，也不会将相关性写成因果。
