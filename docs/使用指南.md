# 使用指南

## 1. 启动本地工作台

安装 Node.js 22 或更高版本，然后在仓库根目录依次运行 `npm.cmd install`、`npm.cmd run db:setup`、`npm.cmd run dev`。开发命令会启动浏览器页面及本地 API；使用期间请保持终端窗口开启。

如果 `npm.cmd run db:setup` 失败，先运行 `npm.cmd run db:generate`，并查看完整报错。不要为了“修复”问题而删除已有的 `data/` 目录，其中可能包含你的本地分析数据库。

## 2. 准备导出表

从内容、电商或广告平台导出 CSV/XLSX。每一行应代表可比的一个单元，例如同一素材的一天、一个广告计划或一个统计周期。尽量保留这些字段：

| 用途 | 推荐字段 |
| --- | --- |
| 标识 | 素材 ID/名称、平台/渠道、日期或日期范围、数据来源 |
| 投放上下文 | 账户、计划/广告组、目标、归因窗口 |
| 视频 | 展示、播放/观看、观看时长、完播 |
| 流量 | 点击、商品点击 |
| 电商 | 加购、支付、订单、GMV/成交额；如有可加入退款 |
| 成本 | 消耗、CPM、CPC、CPA、ROI 或 ROAS |

系统可识别 `campaign_name`、`purchases`、`revenue`、`roas` 等常见别名。遇到未内置的平台，直接填写平台名称即可；导入器会生成安全的自定义渠道代码。

不要把归因窗口或日期范围不同的数据放在同一比较中。例如“TikTok Shop 最近 7 天的归因购买”和“当天实时订单”都可能正确，但不是同一条可直接比较的序列。

## 3. 安全导入

1. 打开“数据导入”，选择最接近你导出表的导入类型。
2. 选择 CSV 或 XLSX；写入数据库前会先校验文件。
3. 多工作表文件请选中数据页。含公式的数据页会被拒绝；请先将数据复制为值到新的干净工作表。
4. 查看字段映射和预览，修正空素材 ID、日期无效、数值列混入文本等问题。
5. 确认预览正确后再导入；导入历史会记录这一批次。
6. 如果导入有误，使用该批次的“撤销/回滚”。它只会撤销选定批次，不会删除其他数据。

本地服务会限制文件类型、大小、行数和危险公式前缀，并且不会执行 Excel 公式。

## 4. 如何看分析，才不会误判

先锁定同一平台、同一统计周期和同一投放范围，再按漏斗查看：

1. **曝光与注意力：** 展示、播放、观看时长、完播。
2. **兴趣：** CTR 与商品点击率。
3. **购买意图：** 加购率、支付率。
4. **结果与效率：** 订单、成交额、CPA、ROAS。

页面中把鼠标移到或点击指标帮助标记，可以看到定义、公式、方向和看法。CTR 高但购买率低不一定是好事，可能是素材吸引来的用户与商品承诺不匹配。ROAS 高也不等于利润，它会受归因、退款和极小消耗基数影响。

趋势只能说明“发生了变化”，不能单独证明原因。决定加投、暂停或改素材前，还应检查受众、目标、版位、出价、素材版本，以及平台归因定义。

## 5. 使用可选智能体 Skill

插件位于 `plugins/clipcommerce-analyst`。其中首选的可选 Skill 是 `adaptive-work-improvement`：用于在不替换现有工作流的前提下帮助智能体改进工作。它从观察模式开始，任何改动都需要明确授权，也不要求使用本地工作台或上传数据。已有的 `video-commerce-analysis` Skill 则保留给你明确需要分析导出表现表时使用。

安装前请阅读 [Skill 优先使用方式](skill-first-adoption.zh-CN.md)。保留宿主智能体的既有配置，只将本插件作为可选能力加入；不要覆盖它原有的提示词或 Skill。

未经组织批准，请不要将保密导出表发送给远程助手或第三方服务。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 浏览器打开是空白 | 先运行 `npm.cmd run build`。若失败，先修复终端报错；然后重启 `npm.cmd run dev`，并打开终端显示的准确 localhost 地址。 |
| XLSX 因公式被拒绝 | 复制文件，在新的可见工作表中粘贴为值并保存，再导入该副本。不要修改原始导出表。 |
| 列没有被识别 | 手动映射，并使用稳定字段名，如 `asset_code`、`channel`、`date`、`impressions`、`clicks`、`orders`、`revenue`、`spend`。常见平台表头缺失时，可提供脱敏后的表头行提交 Issue。 |
| 数字不对 | 检查小数点、币种单位、日期范围、时区，以及收入是含税/未税、实收/GMV、归因/实时。 |
| 自定义平台不能比较 | 仍可导入，但要保留来源和归因上下文，只比较口径兼容的行，并在本地指标备注中记录定义。 |
| 导入了一批错误数据 | 在导入历史中回滚准确的那一批。不要一开始就删除本地数据库。 |
| 数据库命令失败 | 保持数据库本地，运行 `npm.cmd run db:check`，在支持请求中提供脱敏后的完整报错。 |

其他问题请查看 [SUPPORT.md](../SUPPORT.md)。怀疑安全漏洞时，**不要**提交公开 Bug，请遵循 [SECURITY.md](../SECURITY.md)。
