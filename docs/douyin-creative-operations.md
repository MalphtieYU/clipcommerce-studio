# 抖音 / 巨量千川创意实验工作流

ClipCommerce Studio 的通用导入能力仍可用于其他视频电商平台；但当前产品把 **抖音 / 巨量千川素材投放复盘** 作为第一优先级。它只读取用户主动导出的 CSV/XLSX，不登录、抓取、控制或代替任何平台账号。

## 先把创作想法变成可检验标签

在“素材资产库”新建/编辑素材，或在“数据导入 → 素材元数据”中映射以下可选字段：

| 字段 | 用途 | 填写原则 |
| --- | --- | --- |
| 内容方向 | 区分正在测试的方向 | 同一批要可区分，例如场景痛点、剧情对话、使用演示 |
| 核心卖点 | 检查单条素材是否聚焦 | 每条填 1 个；尾部延展卖点不要再填成第二个核心 |
| 开头钩子 | 记录前几秒的留人表达 | 写可辨认的钩子类型或文案骨架，不要只写“新文案” |
| 达人/创作者、达人新鲜度 | 观察素材来源是否过度复用 | 使用内部代号即可；新 / 复用 / 未知必须如实标注 |
| 素材载体、投放目标、场景 | 控制实验变量 | 例如短视频、商品卡、直播切片；推商品、推直播、测试 |
| 脚本族 | 识别重复迭代 | 同一复刻框架使用同一个名称，方便人工审片 |

工作台只提示“标签重复”或“字段缺失”，不会把它自动定性为失败素材。画面、卖点合规、定向、人群、预算、竞价、投放周期和归因窗口都可能影响结果。

## 建议的测试顺序

1. 先做可区分的新钩子 + 新出镜/新创作者组合，避免只对旧素材换词。
2. 再比较不同内容载体和场景，例如原生场景一镜到底、对话/剧情、沉浸式开箱或使用演示。
3. AI 画面类内容应小规模单列测试，不能与实拍素材混为同一变量。
4. 每次只优先改变少数变量；在相同渠道、统计周期、投放范围、归因口径下再比较。

“创作策略实验室”按你的实际标签汇总内容方向，并显示同脚本族的复用提醒。CTR、CVR、支付 ROI 仅展示为已导入快照的简单平均数，不能用来证明内容变化造成了结果变化。

## 指标与边界

- 常用关系是 `消耗 = CPM × 展现 / 1000`、`CTR = 点击 / 展现`；CVR 的分母必须以平台导出字段为准（可能是点击、商品点击或其他口径）。
- 支付 ROI / ROAS 是金额回报与消耗的比值，不是利润；退款、平台费、优惠和履约成本需要另行纳入。
- 不把“自然 + 付费”直接称为增量。要判断增量，需要有可比的对照设计或平台认可的实验方法。
- 不把任意“CTR × CVR × 出价”写成 eCPM 的通用公式；不同平台的优化目标、计费和归因规则不同。

具体字段、归因和报告解释应以账户当期产品说明为准。工作台内的指标词典保留官方链接，方便在导入前复核。
