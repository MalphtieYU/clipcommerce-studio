# 开发日志

## 初始化

- 创建独立本地仓库与 `main` 分支。
- 建立内部私有使用说明、环境变量样例和忽略规则。
- 明确不连接公共部署平台或真实业务系统。

## 数据模型

- 增加 Prisma SQLite Schema，覆盖目标、素材/版本、经营快照、逐秒互动、内容段、导入、复盘、周报与审计。
- 提供可复现的本地 SQLite 初始化脚本与初始迁移 SQL。
- 经营字段默认可空，防止缺失值被错误解释为零。

## 第一阶段本地 MVP

- 实现桌面 App Shell 与匿名演示数据导航。
- 实现经营目标、产品知识、素材资产、导入基础流程、指标口径、表现分析、素材复盘、周会报告及逐秒分析工作台。
- 增加导入文件类型、大小与公式注入中和的自动测试。
- 所有页面显示“演示数据”，并对数据不足与待确认状态显式建模。

## 导入模板与收尾验证

- 新增月度目标、每日进度、素材表现、逐秒互动、素材元数据与周报源数据六类双语 XLSX 模板；每份包含字段说明和导入数据工作表。
- 模板中的示例均为匿名占位信息；空值规则明确区分缺失与数值 0。
- 通过导入、结构检查和视觉渲染验证了逐秒互动模板的字段完整性与可读性。
- 移除脚手架品牌资源，更新页面语言与标题为 SleepFlow Studio。

## 数据呈现与指标可理解性调整（2026-07-18）

- 数据总览、单条素材分析和素材对比只展示用户后续确认导入的数据；既有匿名样本不再作为可分析素材、指标或对比结果出现。
- 导入记录仅显示本浏览器在本次产品流程中确认写入的批次，避免开发测试批次干扰用户；真实导入仍保留状态、时间与撤销入口。
- 移除 CTR × CVR 象限与随机点位。真实数据达到两条且口径一致后，改用标明横轴含义的 CTR 条形对比。
- 加入点击/悬停可展开的指标说明，并将指标词典扩展为 31 项电商、短视频、投放、交易与售后指标；每项均包含定义、公式、读法、高低含义、比较前提和数据来源。
- 已通过类型检查、静态规范、单元测试、生产构建和浏览器回归检查。
