# 开发日志

## 初始化

- 创建独立本地仓库与 `main` 分支。
- 建立内部私有使用说明、环境变量样例和忽略规则。
- 明确不连接公共部署平台或真实业务系统。

## 数据模型

- 增加 Prisma SQLite Schema，覆盖目标、素材/版本、经营快照、逐秒互动、内容段、导入、复盘、周报与审计。
- 提供可复现的本地 SQLite 初始化脚本与初始迁移 SQL。
- 经营字段默认可空，防止缺失值被错误解释为零。

## 第一阶段本地 MVP

- 实现桌面 App Shell 与匿名演示数据导航。
- 实现经营目标、产品知识、素材资产、导入基础流程、指标口径、表现分析、素材复盘、周会报告及逐秒分析工作台。
- 增加导入文件类型、大小与公式注入中和的自动测试。
- 所有页面显示“演示数据”，并对数据不足与待确认状态显式建模。

## 导入模板与收尾验证

- 新增月度目标、每日进度、素材表现、逐秒互动、素材元数据与周报源数据六类双语 XLSX 模板；每份包含字段说明和导入数据工作表。
- 模板中的示例均为匿名占位信息；空值规则明确区分缺失与数值 0。
- 通过导入、结构检查和视觉渲染验证了逐秒互动模板的字段完整性与可读性。
- 移除脚手架品牌资源，更新页面语言与标题为 SleepFlow Studio。

## 数据呈现与指标可理解性调整（2026-07-18）

- 数据总览、单条素材分析和素材对比只展示用户后续确认导入的数据；既有匿名样本不再作为可分析素材、指标或对比结果出现。
- 导入记录仅显示本浏览器在本次产品流程中确认写入的批次，避免开发测试批次干扰用户；真实导入仍保留状态、时间与撤销入口。
- 移除 CTR × CVR 象限与随机点位。真实数据达到两条且口径一致后，改用标明横轴含义的 CTR 条形对比。
- 加入点击/悬停可展开的指标说明，并将指标词典扩展为 31 项电商、短视频、投放、交易与售后指标；每项均包含定义、公式、读法、高低含义、比较前提和数据来源。
- 已通过类型检查、静态规范、单元测试、生产构建和浏览器回归检查。

## 平台口径、趋势分析与自动复盘调整（2026-07-18）

- 指标词典增加抖音/巨量与天猫/生意参谋筛选、官方依据链接和“平台原生字段 / 工作台计算”标识；具体来源见 `docs/platform-metric-sources.md`。
- 素材表现导入扩展为可接收展示、播放、点击、商品点击、加购、支付、成交/支付金额、CTR、CVR、ROI 和统计结束日期。
- 素材接口保留同一素材最多 120 条按日期排序的经营快照；单条素材工作台可基于两个以上真实日期点绘制可切换指标趋势曲线，并输出仅描述数据变化的事实说明。
- 从主导航移除手写“周度复盘”；改为“自动复盘报告”入口，明确只有在趋势数据积累后才生成可审查报告。

## 截图整理工作簿安全导入修复（2026-07-18）

- XLSX 解析从“任一页有公式即拒绝”调整为“优先选择无公式的导入数据页”。其他页签的公式既不执行也不读取；当前导入页仍拒绝公式、隐藏工作表和隐藏行列。
- 支持从非首行识别字段表头，适配“标题行 + 字段行 + 数据行”的截图整理表，并自动识别 `material_name`、`material_id`、`transaction_amount`、`paid_roi` 等字段。
- 截图数据缺少渠道或统计周期时，导入页面会让用户明确补充；`0` 和 2000 年以前的占位日期不会作为真实统计日期写入。
- 素材表现导入在素材尚不存在且提供素材名称时，可创建最小素材记录及对应快照；整批导入仍可撤销。
- 使用 `SleepFlow_素材数据_截图整理测试.xlsx` 完成解析与校验回归：识别 5 行，未写入用户数据。

## 通用视频电商公开版准备（2026-08-09）

- 产品名称调整为 ClipCommerce Studio，定位从内部睡眠渠道工作站改为本地优先的视频电商分析工作台。
- 渠道代码改为可扩展文本；内置抖音、TikTok Shop、天猫、京东、Shopify、Meta Ads、YouTube / Google Ads、Amazon，并允许导入自定义渠道。
- 素材表现导入新增广告账户、广告计划、订单、成交金额、ROAS、CPM、CPC、CPA 等字段，保留平台和统计周期以防跨口径误比。
- 新增公开发布计划，记录平台调研依据、未完成安全项与需要负责人确认的许可证/发布范围。
