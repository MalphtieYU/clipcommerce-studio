# 开发日志

## 初始化

- 创建独立本地仓库与 `main` 分支。
- 建立内部私有使用说明、环境变量样例和忽略规则。
- 明确不连接公共部署平台或真实业务系统。

## 数据模型

- 增加 Prisma SQLite Schema，覆盖目标、素材/版本、经营快照、逐秒互动、内容段、导入、复盘、周报与审计。
- 提供可复现的本地 SQLite 初始化脚本与初始迁移 SQL。
- 经营字段默认可空，防止缺失值被错误解释为零。

## 第一阶段本地 MVP

- 实现桌面 App Shell 与匿名演示数据导航。
- 实现经营目标、产品知识、素材资产、导入基础流程、指标口径、表现分析、素材复盘、周会报告及逐秒分析工作台。
- 增加导入文件类型、大小与公式注入中和的自动测试。
- 所有页面显示“演示数据”，并对数据不足与待确认状态显式建模。
