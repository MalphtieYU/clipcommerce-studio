# Code of Conduct / 行为准则

## Our pledge / 我们的承诺

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of experience, identity, background, or role.

我们致力于建设友善、尊重、无骚扰的社区。无论经验、身份、背景或角色如何，每个人都应受到平等尊重。

## Expected behavior / 期望行为

- Be constructive, specific, and kind. / 保持建设性、具体和友善。
- Respect privacy and data boundaries. / 尊重隐私与数据边界。
- Challenge ideas and evidence, not people. / 讨论观点和证据，不攻击个人。
- Welcome correction on platform terminology and metric definitions. / 欢迎对平台术语和指标口径进行纠正。

## Unacceptable behavior / 不可接受的行为

Harassment, discrimination, threats, doxxing, sharing confidential data, and deliberately misleading technical or metric claims are not acceptable. 骚扰、歧视、威胁、人肉、泄露保密数据，以及故意误导技术或指标口径的行为均不可接受。

## Enforcement / 处理方式

Maintainers may remove, edit, or reject contributions that violate this policy. After publication, report conduct concerns privately through the repository’s Security Advisory flow when a public issue would increase harm. Do not use that channel for ordinary product disagreements.

维护者可移除、编辑或拒绝违反本准则的贡献。公开仓库创建后，如公开讨论会扩大伤害，请通过仓库的私有 Security Advisory 流程报告行为问题；普通产品分歧请勿使用该渠道。
