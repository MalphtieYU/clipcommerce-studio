# Support / 使用支持

## Before opening a request / 提问前请先检查

1. Read the [English user guide](docs/USAGE.md) or [中文使用指南](docs/使用指南.md).
2. Run `npm.cmd run build` and `npm.cmd run db:check`.
3. Check whether the issue is about a platform definition, an import mapping, or a defect in the application.

## What to include / 请提供的信息

- Operating system, Node.js version, and the command you ran / 操作系统、Node.js 版本与所运行命令。
- A redacted error message and reproducible steps / 脱敏后的完整报错和复现步骤。
- Platform, date range, attribution type, and metric definitions for analytics questions / 分析问题请说明平台、统计周期、归因类型和指标口径。
- A redacted header row or synthetic sample only—never upload customer data, raw exports, media, keys, tokens, or internal reports / 仅提供脱敏表头或合成样例，绝不上传客户数据、原始导出表、素材、密钥、令牌或内部报告。

## Where to ask / 在哪里提问

After publication, use GitHub Discussions for usage questions and the issue templates for confirmed bugs or feature proposals. Suspected vulnerabilities must be reported privately under [SECURITY.md](SECURITY.md), not in a public issue.
