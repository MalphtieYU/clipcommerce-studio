# SleepFlow Studio｜睡眠渠道内容增长工作站

> 内部私有工作站。仅支持本地、受控内部运行；不得部署到公共平台，不得提交公司真实数据、素材、截图、密钥或内部报告。

SleepFlow Studio 用于管理睡眠产品的视频内容生产、素材版本、渠道经营数据、逐秒互动分析、复盘与周会准备。首期范围覆盖抖音、天猫和京东的人工数据导入工作流。

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

生产构建与检查：

```powershell
npm.cmd run lint
npm.cmd run test
npm.cmd run build
```

## 数据与隐私

- 仅使用匿名演示数据；页面会显式标识“演示数据”。
- `.env`、本地数据库、导入文件、导出文件、视频与图片均被 `.gitignore` 排除。
- 文件导入必须经过类型、大小、字段、口径和公式注入校验后，才可进入确认步骤。
- 删除、导入撤销、导出与诊断操作应保留审计信息；任何高风险业务动作均需人工确认。

详见 `docs/` 下的项目、数据、隐私、安全与测试文档。
